# Faro

Lanzador y centro de automatizaciones para macOS y Windows: abre apps, busca archivos con
vista previa, controla la música (Spotify, Música, YouTube), pega snippets, revisa tu
portapapeles y lanza tus propios comandos, todo con el teclado.

**Web:** https://gscporras.github.io/faro/

## Instalar

**macOS con Homebrew**

```sh
brew tap gscporras/faro https://github.com/gscporras/faro && brew install --cask faro
```

**Descarga directa:** el `.dmg` (macOS, Apple Silicon e Intel) y el `.exe` (Windows) están en
[Releases](https://github.com/gscporras/faro/releases/latest).

> Faro todavía no está firmado por Apple: la primera vez, abre **Ajustes del Sistema →
> Privacidad y seguridad** y pulsa **«Abrir igualmente»**.

Este repositorio solo contiene la web, las descargas y la fórmula de Homebrew; se actualiza
automáticamente con cada versión.
